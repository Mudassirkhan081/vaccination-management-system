A child's paper vaccination card, turned into a live schedule.

TeekaCard tracks every dose a child is due. Parents see the due dates and book a hospital visit, the hospital records what was actually given, and the administrator approves requests and prints date-wise reports.

  • MySQL / MariaDB
  • Bootstrap 5
  • Chart.js
  • Apache / XAMPP
  • 3 user roles
  • 10 tables

Why this page shows screenshots instead of a running app

TeekaCard is a server-side PHP application with a MySQL database. GitHub Pages only serves static files, so it cannot run PHP. This page is a complete walkthrough of the real application, captured screen by screen. To use the working system, follow Run it locally — it takes about five minutes with XAMPP.

The public site

Anyone can read the routine vaccine schedule, work out a due date from the child's birth date, and search the hospital directory before registering.

Three roles, three different jobs

Each role sees only what it needs. A hospital never sees another hospital's appointments, and a parent never sees another parent's children.

Parent

Adds children, reads the digital vaccination card, books a hospital visit, records earlier doses from the paper card, and prints a report.

Hospital

Registers and waits for approval, then works through today's, upcoming and past appointments, marking each vaccine Given or Not given with a remark.

Administrator

Approves parent requests and hospitals, manages the vaccine list, follows every booking on a timeline, and prints date-wise and child-wise reports.

Parent

The dashboard leads with what is overdue and what is coming, because that is the only reason a parent opens the app.

Hospital

Run it locally

Everything is in the repository, including the database dump and the demo data. No internet connection is needed once XAMPP is installed.

  1. Copy 1_Source_Code/vms into C:\xampp\htdocs\.
  2. Start Apache and MySQL from the XAMPP control panel.
  3. Open localhost/phpmyadmin, click Import and choose vms/database/vaccination_db.sql. It creates the database, all ten tables and the demo data.
  4. Open localhost/vms/ and sign in with one of the demo accounts below.
